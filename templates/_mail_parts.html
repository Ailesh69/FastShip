{# Reusable email fragments. Macros rather than includes so each one takes arguments and there is exactly one definition of a detail row, a status chip and a call-to-action button across all seven emails. Everything is inlined and table-based for the reasons documented at the top of _mail_base.html. #} {# The site's two typefaces, defined HERE rather than in _mail_base.html because an {% import %}ed template does not inherit the importer's variables — a macro referencing a name set in the base would render an empty font-family and silently drop back to the client default. _mail_base.html imports these back out as parts.F_PIXEL / parts.F_TERM, so there is still one definition. 'Press Start 2P' for headings, labels, chips and buttons; 'VT323' for body copy and data values — the same split the frontend uses (--font-pixel / --font-term in src/index.css). Courier is the fallback for clients that strip @font-face. #} {% set F_PIXEL = "'Press Start 2P','Courier New',Courier,monospace" %} {% set F_TERM = "'VT323','Courier New',Courier,monospace" %} {# One label/value line inside the detail panel. `last` drops the divider on the final row so the panel doesn't end on a rule. #} {% macro row(label, value, last=false) %} {{ label }} {{ value }} {% endmacro %} {# A row whose value is a status chip. Kept separate from row() so the chip markup lives in one place. #} {% macro row_status(label, tone, text, last=false) %} {{ label }} {{ text }} {% endmacro %} {# Call to action. A bordered table cell wrapping a block-level : the cell paints the fill for clients that ignore link backgrounds, and the anchor fills the cell so the whole box is clickable. #} {% macro button(href, label, fill='#7de87e') %}
[ {{ label }} ]
{% endmacro %} {# Highlight panel — the OTP box and the "link not working" fallback both use it. `tone` sets the border and label colour. #} {% macro notice(tone) %}
